# CAD 几何表示、基元拟合与程序重建

这是一套面向研究入门的中文讲义：假设你学过线性代数、微积分和深度学习，但没有学过 CAD。目标是读懂截图中的五篇论文，知道它们分别恢复了什么结构、依赖什么数学工具、可以支持什么结论。

**主线：理解表示 → 掌握拟合 → 重点读 SuperFit → 学 CSG 结构推断 → 理解 CAD 操作序列 → 研究生成数据与模型。**

补充阅读集中在 **2024–2026 年**；较早论文只保留截图指定的 UCSG-Net 和 D²CSG，nTop 原始入门文章也保留。基础概念直接讲解，不额外布置早期文献。

论文讲解结构与本地 PDF 核对日期：2026-09-23；原有网页资料的核验日期见参考资料。文中“论文结论”指作者在其协议下的报告；“讲义推导”“教学示例”“研究判断”是为理解而添加的内容，并非原论文的新实验。

## 两条阅读路线

**先理解导师强调的内容：** 00 → 01 → 02 的前五节 → 03。完成后应能解释 SuperFit 为什么同时需要新的基元和新的拟合策略。

**完整精读：** 按 00–07 顺序阅读，每章先看讲义，再按阅读定位核对论文公式和图表，最后做习题。不要一开始就追逐所有扩展论文。

## 论文讲解的统一结构

03–06 的五篇核心论文逐篇采用以下结构；04 中 UCSG-Net 与 D²CSG 各自完整展开。07 的七篇扩展论文沿用相同结构简述。

| 阅读顺序 | 应能回答的问题 |
|---|---|
| 1. 前置知识 | 需要哪些概念与数学定义，它们用在哪一步？ |
| 2. 动机 | 输入与输出是什么，已有方法具体缺在哪里？ |
| 3. 贡献 | 作者新增了什么，如何对应到方法和实验？ |
| 4. 方法流程 / Pipeline | 每步接收什么、计算什么、产生什么；训练与推断如何区分？ |
| 5. 实验 | 数据、基线、指标、主结果和消融支持哪些结论？ |
| 6. 局限性 | 什么条件下会失败，表示、数据和计算成本有哪些限制？ |

核心论文的 pipeline 图放在方法部分。公式在对应步骤解释；作者结果注明表号和评价协议。扩展论文的实验数字同样按本地原文核对，不把生成指标与重建指标混合排名。

## 使用方法

Markdown 使用 `$...$` / `$$...$$` 数学公式，可在支持数学的 GitHub 或 Markdown 阅读器中查看。图示为本讲义原创 SVG，附文字说明；不需要安装 CAD 软件。小型可运行算例位于 [examples](examples/README.md)，只需 Python 标准库，用于核验基础概念，不是论文复现。

原论文 PDF 位于仓库的 `papers/`，版本及阅读位置见 [参考资料](references.md)。本讲义中的论文实验数字为作者报告，没有将本项目的独立基元拟合实验当作论文复现。
