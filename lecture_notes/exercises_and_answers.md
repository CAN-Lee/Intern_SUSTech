## 01 · 几何表示

2. 还缺每个面的有限裁剪域、外环内环、共享边连接、方向以及壳/实体组织。曲面方程只提供支撑几何。

## 02 · 数学与优化

1. $\max(2,1)=2$，真实距离为 $\sqrt5\approx2.236$。
2. $d(x)=3(\|x/3\|-1)=\|x\|-3$。漏乘 3 后零集不变，距离值缩小三倍。
3. $X\to Y$ 项为 0；$Y\to X$ 为 $(0+4)/2=2$；按本章定义双向和为 2。
4. 比较 $0.95-5\lambda>0.96-20\lambda$，得 $\lambda>0.01/15\approx0.0006667$；等号时同分。
5. 两场都为 $f$ 时，$\operatorname{smin}_\tau(f,f)=f-\tau\log2$。新零集满足 $f=\tau\log2$，若 $f$ 为精确 SDF 就相当于向外偏移该距离。

## 03 · SuperFit

1. 八个参数控制局部形状；放入世界坐标还要平移和旋转，软并装配另有混合参数。旋转实现中四元数的四个分量也不是四个独立旋转自由度。
2. 在 $p=(h_x,0)$，$q=(r,-h_y+r)$；第二分量非正，距离为 $r+0-r=0$。
3. 失去对早期过拟合或欠拟合区域重新分配容量的能力，新基元可能只能补碎片，无法让旧基元让出空间。
4. 可能删除太多部件并欠拟合。质量项抑制重叠/过度平滑，不直接等于总基元数；很多互不重叠的小块仍可能过长。
5. 3DGen-Prim：提升 $88.74-82.67=6.07$ 个百分点，基元减少 $(42.96-23.98)/42.96\approx44.18\%$。Toys4K：提升 9.32 个百分点，基元减少约 22.70%。若算 IoU 相对增长，分别约 7.34% 和 11.56%，不要与百分点混淆。

6. 输入是目标及当前装配，计算残差后由 MSD 初始化新基元，联合优化新旧参数、剪枝并更新最佳装配。Table 3 的 Single-shot + MSD 与 ResFit + MSD 对照检验迭代残差重分配；IoU 从 87.95 到 89.86。

## 04 · 神经 CSG

1. 三组输入的（并、交、A差B）分别为 $(1,0,1)$、$(1,1,0)$、$(1,0,0)$。每一项都由裁剪公式直接得到。
2. 若点各自选择不同结构，就不能导出同一组全局几何参数和树来解释所有查询点，会把空间场拟合与程序结构混淆。
3. Con 对该列处处为零；按空交集约定相当于全域。必须结合有效节点/屏蔽规则处理，而不是把它误当成空实体。
4. $A\setminus(B\setminus C)=A\cap\neg(B\cap\neg C)=A\cap(\neg B\cup C)=(A\cap\neg B)\cup(A\cap C)$。差运算隐藏了对某些基元的反向成员条件。
5. 有限点可能全部错过很薄的结构、窄缝或小孔。增加采样和局部检查能提高可信度，但有限随机采样本身不是连续等价性的严格证明。

6. UCSG-Net 使用已训练的 encoder/decoder 预测，再硬选择、回溯和执行 CSG；D²CSG 为新目标重新初始化 latent/网络，分阶段优化、剪枝后导出。完整端到端成本包含的工作不同，单个前向耗时不能代表求解总成本。

## 06 · Zero-to-CAD

1. 总是输出一个固定合法盒子，就可能有极高执行率，但不能重建多样目标。
2. 基础模型已有预训练知识，类别、prompt、参考模式和执行 API 也提供先验。缺少的是该任务的真实 CAD 构造历史数据来源。
3. 通过了导出检查，可能也通过执行与几何有效性。还需测目标几何匹配、孔位置/孔径约束或描述满足度。
4. A：$0.5\times0.9=0.45$；B：$0.9\times0.6=0.54$。按此口径 B 更好，但若使用场景允许无限重试，成本与指标还需重新定义。

6. 下游使用完整数据集中的 979,633 个训练样本，另有 10,000 validation 和 10,000 test。精选集是另一份数据产物。代理修复改变当前代码和上下文，SFT 更新重建模型参数。
