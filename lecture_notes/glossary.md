# 术语与符号速查

[总目录](README.md)

## 术语

| 英文 | 中文 / 本讲义含义 | 易混点 |
|---|---|---|
| solid | 有内部的实体区域 | 一张开放曲面不自动定义实体 |
| boundary / surface | 边界 / 曲面 | 无边界裁剪的曲面不等于 face |
| B-rep | 边界表示：几何与拓扑共同组织 | 不自动包含原始建模历史 |
| topology | 实体之间的连接和关联 | 不是几何坐标本身 |
| coedge | 一条边在某个面环中的有向使用 | 同一 edge 可被多个面使用 |
| wire / loop | 边组成的环或线框 | 面可有外环和孔的内环 |
| trimming | 曲面参数域的裁剪 | 保留有限区域而非整张无限曲面 |
| watertight | 水密、封闭 | 还应考虑自交、定向和退化 |
| tessellation | 曲面离散成面片 | 不保留所有原始参数信息 |
| implicit field | 隐式标量场 | 不一定是距离 |
| occupancy | 占据，内部为 1 | 本讲义 SDF 内部为负 |
| SDF | 符号距离场 | 精确 SDF 在可微处梯度模长为 1 |
| ASD | 近似符号距离 | D²CSG 中由二次隐式值构造 |
| primitive | 基元 / 参数化基本形状 | 不一定是球、盒等标准实体 |
| quadric | 二次曲面 | 与 superquadric 的指数参数化不同 |
| superquadric | 超二次曲面家族 | superellipsoid 只是其中一种 |
| frustum | 截锥 / 截头体 | SuperFrustum 的形状范围更广 |
| taper | 锥度、沿轴尺寸变化 | 不等于刚体旋转 |
| onion / shell | 壳状或中空控制 | 不自动对应工程上恒定壁厚 |
| CSG | 构造实体几何 | 基元加布尔结构，不等同完整特征历史 |
| smooth union | 平滑并 | 改变零水平集，不是精确集合并 |
| MSD | 形态学形状分解 | 以腐蚀、膨胀和连通性提案 |
| ACD | 近似凸分解 | 凸性目标未必匹配弯曲或中空基元 |
| residual | 尚未解释或多解释的几何 | 三篇相关方法的具体定义不同 |
| parsimony | 紧凑、少冗余 | 不能只追求最低基元数 |
| pruning | 剪枝 | 删除节点后须重新检查输出 |
| amortized inference | 训练后复用的推断 | 不等同单形状从头优化 |
| TTO | 测试时优化 | 比较时间时应计入 |
| sketch / extrude / revolve | 草图 / 拉伸 / 旋转 | 操作依赖轮廓和坐标系 |
| fillet / chamfer | 圆角 / 倒角 | 依赖已存在的边与实体 |
| design intent | 设计意图与参数关系 | 不能由几何误差单独证明 |
| CAD kernel | 几何内核 | 执行曲面、拓扑与实体运算 |
| DFM | 面向制造的设计要求 | 几何有效性不足以覆盖它 |
| IoU / CD / IR | 交并比 / Chamfer / 无效率 | 同名指标仍需核对协议 |
| SFT / RL | 监督微调 / 强化学习 | 与推断时修复区分 |

## 符号

| 符号 | 全书通用含义 |
|---|---|
| $S,M$ | 目标实体、目标 Mesh；使用体积运算时假设 Mesh 定义实体 |
| $x,p,q\in\mathbb R^3$ | 查询点，$q$ 常表示局部坐标点 |
| $\partial S$ | 实体边界 |
| $d_S$ | 明确指精确符号距离时使用 |
| $f,F$ | 一般隐式场，或装配场 |
| $\chi_S,o$ | 二值占据、连续占据近似 |
| $R,t$ | 刚体旋转与平移；在评分上下文中 $R(\cdot,\cdot)$ 为重建质量 |
| $\theta$ | 连续参数向量 |
| $T$ | CSG 树；在 D²CSG 的局部定义中为选择矩阵 |
| $P$ | 构造程序：描述基元、尺寸、位姿及组合或加工操作，可以表示为表达式、树或代码 |
| $z,\Pi$ | 程序 / 装配的其他局部记法；具体含义随论文定义 |
| $E$ | 执行器，将构造程序转成几何结果 |
| $E(P)$ | 执行程序后得到的形状 |
| $\mathcal L_{\mathrm{geom}}(E(P),S)$ | 生成形状与目标几何之间的误差，越小越好 |
| $C(P)$ | 程序复杂度，例如基元数、树大小或操作数 |
| $\lambda$ | 权衡系数；统一优化框架中为非负的复杂度权重 |
| $\operatorname*{arg\,min}_{P}$ | 返回使目标函数最小的程序，而不是最小函数值 |
| $P^*$ | 所选候选空间中的最优程序，可能不唯一；实际算法可能只得到近似解 |
| $\tau$ | 温度；MSD 原文负阈值在讲义中改记 $\ell$ |
| $\alpha$ | UCSG-Net 的占据过渡宽度；其他论文使用时单独定义 |
| $m$ | D²CSG 最终差集的 margin，原文使用 $\alpha$ |

每篇论文的符号是局部作用域。相同字母不是跨论文同一个参数，尤其注意 SuperFit 的 bulge 在正文记 $b$、补充记 $c$。
