# Fusion 360 Gallery Mesh 案例

这里是 Autodesk [Fusion 360 Gallery Dataset 分割数据集 s2.0.1](https://github.com/AutodeskAILab/Fusion360GalleryDataset) 中的 **9 个模型子集**，用于本地非商业研究。原始数据及其许可证归 Autodesk 所有，具体条款见 [LICENSE.md](LICENSE.md)。本目录不是完整数据集。

每例包含原始的闭合 OBJ Mesh，以及对应的 `timeline_info` JSON。OBJ 是拟合输入；JSON 记录源 CAD 特征类型，仅用于选例和事后分析。评价纯 Mesh 重建时，不应把 JSON 作为拟合输入。

| 难度 | 案例 ID | 源特征 | 选例说明 |
|---|---|---:|---|
| 简单 | `110956_df981ed9_0` | 1 次拉伸 | 单次建模操作；最终 Mesh 有一个贯穿孔。 |
| 简单 | `129012_576921da_0` | 1 次拉伸 | 单次建模操作；亏格为 0。 |
| 简单 | `23853_4f653200_4` | 1 次旋转 | 单次建模操作；亏格为 0。 |
| 中等 | `132948_7b65c184_2` | 2 次拉伸 | 包含一次切除。 |
| 中等 | `140224_6952f93f_3` | 1 次拉伸、1 次圆角 | 包含曲面过渡。 |
| 中等 | `62111_9ba5436e_2` | 3 次拉伸 | 包含连接和切除。 |
| 困难 | `138244_f79136e9_0` | 4 次拉伸、1 次圆角、1 次倒角 | 包含两次切除；亏格为 1。 |
| 困难 | `96174_fea894a7_0` | 9 次拉伸、1 次圆角 | 同时包含连接和切除。 |
| 困难 | `109857_1d24326e_6` | 20 次拉伸 | 有重复切除；亏格为 17。 |

难度是依据源特征数量、操作组合和拓扑制定的**实验分组**，不是 Autodesk 提供的等级，也不保证实际拟合耗时或误差顺序。源 CAD 历史未必是隐式基元的唯一或最简解释。

9 个 OBJ 均通过 HTTP 字节范围从官方 `s2.0.1.zip` 提取，已核对解压长度和 ZIP CRC。局部拓扑检查显示每条边都恰好属于两个三角形。文件保留数据集原坐标；后续拟合若归一化，应记录变换。

官方压缩包：<https://fusion-360-gallery-dataset.s3.us-west-2.amazonaws.com/segmentation/s2.0.1/s2.0.1.zip>
